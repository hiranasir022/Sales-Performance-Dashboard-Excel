# Sales-Performance-Dashboard-Excel
Interactive Sales Performance Dashboard built in Microsoft Excel using Power Pivot, Data Model, Pivot Tables, Charts, KPIs, and Data Visualization to analyze sales, products, customers, geography, and team performance.
## Project Overview

The Sales Performance Dashboard is an interactive Microsoft Excel project developed to analyze business sales performance using dynamic reporting and visualization techniques. The dashboard combines sales, product, customer, geography, and team data to provide meaningful business insights that support strategic decision-making.

The project integrates multiple datasets, including Sales Data, Product Data, Location Data, and People Data. Advanced Excel features such as Power Pivot, Data Model, Pivot Tables, Pivot Charts, KPIs, conditional formatting, sparklines, formulas, and interactive dashboard elements were used to transform raw data into an informative reporting solution.

The dashboard is divided into four key sections: Overall Business Summary, Geographical Performance, Team & People Performance, and Product Performance. These sections help users evaluate sales trends, compare regional performance, identify top-performing products, monitor team productivity, and understand customer purchasing patterns.
